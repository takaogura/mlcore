## 機械学習

機械学習のアーキテクチャは、以下の3つの独立したパーツの組み合わせ.

1. モデル
   入力Xからどのように予測値を計算するか. その数式の枠組み.

2. 損失関数
   モデルの予測の良し悪しをどう測定するか.

3. 最適化手法
   損失を最小にするためにどのようにパラメータ(w,bなど)を更新するか.

### モデル

### Logistic Regression

1. 線形結合でlogitを計算
   $$z = Xw + b$$

2. logitをシグモイド関数$\sigma(z)$で確率に変換
   $$\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}}$$

   「シグモイド関数を通す前の、モデルが生で出力した予測値」をlogitという.

### 損失

交差エントロピー誤差

$$L = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

線形回帰では、損失関数にMSE(平均二乗誤差)を用いた.
しかしロジスティック回帰でMSEを用いると、損失関数のグラフは綺麗なすり鉢型にならず、勾配降下法で谷底に辿り着けない.
そこで分類問題に特化した「交差エントロピー誤差」を用いる.

### 最適化手法/学習法

損失関数Lの偏微分

$$dw = \frac{1}{n} X^T (\hat{y} - y)$$

$$db = \frac{1}{n} \sum_{i=1}^n (\hat{y}_i - y_i)$$
