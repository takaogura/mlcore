# mlcore

Learning machine learning and deep learning by implementing core algorithms and models from scratch.

## Goals

- Implement core machine learning algorithms from scratch
- Implement neural network components step by step
- Compare custom implementations with PyTorch and scikit-learn
- Write experiments and explanations
- Connect ML/DL foundations to scientific machine learning and protein design
